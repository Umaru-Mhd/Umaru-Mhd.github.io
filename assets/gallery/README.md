# Gallery Images

Add future conference, seminar, workshop, fieldwork, laboratory, and teaching photos in this folder.

Recommended naming pattern:

- `estcon-2026.jpg`
- `university-malaya-visit.jpg`
- `asim-2026-singapore.jpg`
- `gdi-2026-online.jpg`
- `seminar-2026-01.jpg`
- `workshop-2026-01.jpg`

To show a real photo on the website, replace one placeholder in `index.html` with:

```html
<figure class="gallery-card">
  <img src="assets/gallery/estcon-2026.jpg" alt="Umaru Mohammed at ESTCON 2026 in Malaysia">
  <figcaption>ESTCON 2026 / ICSL, Penang, Malaysia.</figcaption>
</figure>
```
